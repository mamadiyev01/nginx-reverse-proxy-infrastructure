# Nginx Reverse Proxy

Nginx acts as a centralized reverse proxy.

## Configuration

- Domain: ogabek.uz
- Protocol: HTTP
- Listening port: 80
- Backend: Windows IIS
- Proxy method: HTTP reverse proxy

## Request Headers

- Host
- X-Real-IP
- X-Forwarded-For
- X-Forwarded-Proto

## Security

The repository contains sanitized configuration examples.
Production IP addresses and private credentials are not published.
